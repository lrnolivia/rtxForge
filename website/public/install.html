Install on Linux.

Choose Beta on the downloads page. It’s the version to start with.

Flatpak

The easiest choice on SteamOS. It also works on Bazzite and CachyOS.

  1. Download the Flatpak.
  2. Open it in Discover or GNOME Software and follow the prompts.
  3. Launch rtxForge from your app menu.
Installing from a terminal?

Run flatpak install --user /path/to/rtxForge.flatpak, using your downloaded filename. You’ll need Flathub’s GNOME runtime and host Python 3. This is a release download, not a Flathub listing.

AppImage

Another option for Bazzite and CachyOS. Allow the file to run as a program in its properties, then open it. Keep it in a permanent folder if you add a shortcut.

AppImage won’t open?

It needs your system’s Python 3, GTK4, libadwaita 1.7+, and PyGObject. On CachyOS, check python-gobject and libadwaita. Also check executable permission and any FUSE error. SteamOS users should choose Flatpak.

Installer

Download and run the installer, then open rtxForge from the Start menu. If it comes in a ZIP, extract it first. The app runtimes are included.

Prefer the portable version?

Extract the entire portable ZIP and open rtxForge.exe. Keep the files together. Settings and backups may still be stored outside that folder.

Requirements and other builds

Linux x86_64 with a working NVIDIA driver.

Keep at least 4 GiB free for runtime setup, plus room for downloads and backups.

Development builds contain newer changes and may be less stable. Check the release notes for package requirements, signing notes, and testing limits.

Try one game first.

  1. Find your game. Rescan the Library. If it’s missing, add its folder in Settings.
  2. Choose what to install. Pick a package in Packages, then NR, MFG, or both. The app shows which options the game supports.
  3. Set your presets. Start with the defaults. NR starts off on a clean install; choose Enable NR on launch in the review if you want it on.
  4. Close the game and install. Choose Install Features, read the changes, and confirm. Keep the original-file backups. Avoid protected online games and anti-cheat.
  5. Play. Turn on the game’s DLSS and frame-generation options as required by your package. Check how it looks and feels before adding more games.

For frame generation, use a Proton build with NVIDIA CUDA support, such as Proton-GE. Run the game once with that build, then quit before setup. Follow the review if it asks you to close Steam.

Packages, presets, and existing mods

A package supplies the game files; a preset holds your tuning. Some NR packages also need a model file. The install review tells you what’s missing.

For an existing manual setup, use Adoption when offered and read what it recognizes. For a managed setup, use repair or restore before switching packages. Unknown files should not be overwritten.

NR is experimental. MFG supports RTX 20, 30, and 40 series on compatible game/package combinations. Selecting 4× does not guarantee four times the measured FPS.

Make changes while you play.

The overlay puts NR and MFG controls inside a compatible game.

  1. Open Settings → Overlay. Choose In the gamertxForge as the primary overlay.
  2. Check Panel shortcut. Use Record to choose your own key. Use the shortcut shown in your build; it can differ between versions.
  3. For an installed game, close it, choose Update Overlays, review, and apply. Restart the game, then press your shortcut.

Start with Unified controls. Adjust what you need and choose Save preset to keep it.

Enable Background overlay helper if you want the controls available after closing the manager. Start with Windows starts just that helper.

Keep rtxForge running for the helper. In Steam Game Mode, use this in-game panel; it doesn’t need a desktop-wide shortcut.

Appearance, shortcuts, and per-game settings

Overlay settings include Dark, Light, Follow app, welcome messages, and live statistics when the runtime provides them. Advanced controls use the package’s own labels and units.

To change one game, open its Overlay controls and turn off Use app overlay settings. Review Update Overlays for that game, then restart it. Older builds may use their install or repair review instead.

Keep the panel key separate from game controls and OptiScaler’s key. Reset restores your build’s default; Disable removes the binding. A saved setting or log entry alone doesn’t prove a visible NR effect.

When you need more.

OptiScaler and ReShade menus

In Settings → Overlay, menu access and welcome messages are separate choices. OptiScaler offers Insert, F8, or Disabled for its menu key. ReShade uses the key in its own configuration.

You can keep these menus alongside the rtxForge panel, or choose NativeOptiScaler menu only as the primary overlay. Review Update Overlays and restart the game.

Hiding a menu or intro keeps NR, MFG, and Feeder effects installed. ReShade/RenoDX loading notices are separate from welcome messages. The native MFG menu is optional on packages that support it.

Play from the couch with Game Mode

Game Mode is the controller-friendly version of the app. It uses the same library, packages, and backups as Desktop. It’s separate from the in-game overlay.

Open Settings → Gaming Mode for interface, controller, scale, and theme choices.

Choose Add to Steam there, then launch the shortcut from Steam’s Game Mode. Close Steam if asked when changing the shortcut.

Follow the on-screen button hints. Long review lists can have controller-scrolling issues in Beta 1.

Change several installed games at once

Open Settings → Global, choose the NR/MFG change, and review the games before applying. Leave anything else as it is. Running games and unsupported or conflicting setups are skipped.

This is a one-time change to existing installs. New installs still use your presets. Unrelated tuning and original-file backups are kept.

Use a shared Windows/Linux library

On Linux, Adapt to Linux sets up supported games already installed with rtxForge on Windows. Use it for one game or the whole library. It leaves the game folder and Windows setup alone.

Start the game once with your chosen Proton build, quit, then review the adaptation. Don’t copy Windows launch settings into Proton by hand.

Update, repair, or undo an install

Repair Feature Files repairs a managed setup while keeping its recorded tuning. Restore Original Files removes it using your backups.

DLSS Files has its own restore controls for native DLL updates. Keep backups and recovery records. If another mod or a game update changed a file, read the conflict before restoring.

Updating the app doesn’t automatically update every game’s feature package. Use the app updater or download the newer build, then review any game changes separately. See the DLSS file guide for more.

Something not working?

The game or a feature won’t work

Check the package, feature mode, and the game’s DLSS/FG settings. For NR, try Game Details → Tools → Diagnose NR. Include any error exactly as shown.

Game support varies by package. Linux Vulkan/Proton games and the Light overlay still have testing limits—check your release notes.

The overlay won’t open or save

Check the panel choice and shortcut in Settings → Overlay. Confirm a compatible package is installed. Close the game, review Update Overlays, and restart.

Check that the background helper is enabled if the manager is closed.

Keep rtxForge open. Saving and replaying presets needs the matching game-side bridge from this release’s Windows build. If it says it’s waiting for the helper, include that message in your report.

Still stuck? Report a bug. Tell us what happened and what you’re using. You can attach logs later.
