# RTXForge 0.5.9

- GNOME sliding mode selector with stable positioning.
- Larger, lighter game titles and accent-colored Details buttons.
- Taller, centered hero images with floating tabs and a fade into the content.
- Appearance page with artwork credits and sampled accent colors.
- Centered tuning controls and a two-tone Settings sidebar with icons.
- Compact progress panels with transitioning hero artwork, a Cancel button, and simplified completion screens.
- Steam artwork matching supports non-Steam shortcut IDs and nested library caches. Local inspection found hero and capsule images for all 38 games, and posters for 36.
- Includes the 0.5.8.1 Bazzite recovery-journal path fix.

Validation: focused desktop transaction tests, host path-alias recovery fixture, and GTK demo checks with screenshots. No live games changed during validation. Gradient fades are used instead of compositor-dependent backdrop blur.

The DLSS updater is not included.
