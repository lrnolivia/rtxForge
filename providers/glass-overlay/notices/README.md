# Dependency provenance

The renderer uses RmlUi, FreeType, Roboto, Bakbak One, Inter and Phosphor icons.
Their licenses accompany the built DLL. The existing product license remains
authoritative for rtxForge source.

This software is based in part on the work of the FreeType Team. The FreeType
library is supplied by the pinned OptiScaler checkout. Its headers identify
version 2.13.3. `FreeType-2.13.3.txt` is the unmodified license from
[the FreeType 2.13.3 source](https://github.com/freetype/freetype/blob/VER-2-13-3/docs/FTL.TXT),
SHA-256 `08c135755dd589039470f1fdbb400daaabaaa50d0b366d19cebff4d22986baa1`.
