Frequently asked
questions.

Which GPUs and games work?

Linux x86_64 with a working NVIDIA driver. Package-specific requirements are listed with each release.

NR works with compatible RTX cards. MFG supports RTX 20, 30 and 40 series. Check compatibility for your game and installed provider. Neural rendering is experimental.

Start with one game. Close it before making changes, review the files, and keep the original-file backups. Avoid protected online games and anti-cheat.

Should I choose Beta or Development?

Start with Beta, the regular public testing release. Development is a moving release with the latest changes and unfinished features.

If a channel says coming soon, its release or a package for your OS has not been published yet. You can also download published packages from GitHub Releases under Assets.

How do I get started?

Download the app package for your OS and channel. In rtxForge, find one compatible game, choose your packages, tune presets, then review and install the features with the game closed.

Follow the installation guide →
Can I undo an installation?

Restore Original Files uses your feature-install backups to remove a managed installation. Native DLL updates made through DLSS Files have their own restore controls.

Keep your backups and recovery records. If a game update or another mod has changed the files, review any restore conflict before replacing them.

Can I use the same games in a dual-boot setup?

That is the goal: install a package on either OS, then adapt the same games on the other in one click. Dual-boot adaptation is a work in progress. Use the adaptation review offered by your build; launch settings differ between Linux and Windows.

I’m having issues with Game Mode or the Overlay

Check the release notes for your OS and build; available controls can differ between versions. For the Windows overlay, open Settings → Overlay to check the shortcut and supported controls.

If the issue persists, include your OS, app build, controller if relevant, and steps to reproduce in a bug report. Use the support-report steps under Found a bug? below to collect the details.

Found a bug?

Open Settings → Recovery → Library Reports → Preview Support Report in rtxForge. Review the report, export it, then attach it to your bug report.

Include your platform, GPU and driver, game, provider, and what happened. Logs and notes are optional. Check the export before sharing; redaction can miss personal information.
